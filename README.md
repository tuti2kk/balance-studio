# Balance & Progression Studio

Веб-сервис для проверки баланса игры: импорт статов, редактор таблицы, калькулятор урона/TTK,
кривая прогрессии, проверка таблиц лута. Чистый HTML/CSS/JS, без сервера и сборки.

## Запуск
Открыть `index.html` двойным кликом в браузере. Всё работает локально, данные хранятся в localStorage.

## Структура
```
index.html            — разметка, вкладки, подключение скриптов
css/style.css         — стили, светлая/тёмная тема
js/utils.js           — общие функции (экранирование, форматирование, скачивание)
js/store.js           — единое хранилище + автосохранение в localStorage
js/parsers.js         — разбор CSV/JSON и валидация юнитов и лута (чистые функции)
js/formulas.js        — все игровые формулы: урон, TTK, опыт, сумма лута (чистые функции)
js/modules/*.js       — по файлу на вкладку: import, table, ttk, progression, loot
js/app.js             — переключение вкладок, тема, запуск модулей
data/                 — тестовые файлы
```

## Формат данных
Обязательные колонки: `id, name, hp, attack, defense, cost`. Числа: `hp, attack, defense, cost` (≥ 0).
CSV: разделитель `,` `;` или Tab определяется автоматически, дробь можно писать через запятую.
JSON: массив объектов или `{"units": [...]}`. Дополнительные колонки сохраняются.

## Модули
1. **Импорт** — CSV/JSON через кнопку или drag&drop. Битый файл не импортируется, ошибки выводятся с номерами строк.
2. **Таблица** — правка ячеек с проверкой, добавление/удаление строк, автосохранение, экспорт CSV/JSON.
3. **Урон / TTK** — формула «процентная броня», криты, TTK для пары, дуэль, матрица всех пар, расчёт по шагам.
4. **Прогрессия** — `XP(L) = round(base × L^power + linear × L)`, пресеты, таблица уровней, график (Chart.js), экспорт.
5. **Лут** — таблицы дропа, проверка суммы = 100%, подсветка ошибок, нормализация, симуляция 10 000 выпадений, экспорт с отчётом.
6. **Аудит (доп.)** — эффективное hp, сила = атака × эфф. hp, ценность = сила / цена; сравнение с медианой: «доминирует» / «бесполезен» / «норма», процент побед в дуэлях, экспорт.

## Формулы
- Урон: `атака × множитель × 100 / (100 + защита)` — защита уменьшает урон, но никогда не обнуляет его.
- Средний урон с критами: `урон × (1 + шанс × (множитель_крита − 1))`.
- Ударов до убийства: `⌈hp / урон⌉`; TTK = удары × интервал атаки.

## Тесты
Формулы проверены вручную на примерах (см. отчёт) и автотестами.
График требует интернета (Chart.js с CDN); без него показывается таблица.
